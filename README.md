# DUELS — Blood & Steel

A complete, shippable 2D fighting game built **from scratch** with HTML5 Canvas + vanilla TypeScript + Web Audio. No engine. No asset packs. No stock sprites. Every pixel, particle and sound is generated by code.

> **Eight fighters. Two factions. One arena. First to two rounds wins.**

---

## Play Now

```bash
npm install
npm run dev    # → http://localhost:5173
npm run build  # production build to dist/
npm run preview
```

Controls: **A/D** or **←→** Move, **W/↑** Jump, **S/↓** Crouch / Hold Back to Block, **J/Z** Light, **K/X** Heavy, **Q** Special 1, **E** Special 2, **R** Ultimate (100 meter), **Shift/Space** Dash, **ESC** Pause. Gamepad supported (axes + first 6 buttons).

## Design System — Why It Doesn't Look Like AI Slop

Before writing any gameplay code, a full design system was defined in `src/styles/design-tokens.css`:

**Palette — "Ink & Blood"**
| token | hex | role |
|---|---|---|
| `--ink-black` | `#09090E` | background, deep ink |
| `--ink-panel` | `#1A1A24` | cards, panels |
| `--line` / `--line-strong` | `#2C2C3D` / `#3A3A50` | borders |
| `--bone` | `#EDEBE3` | primary text, bone-white |
| `--bone-muted` | `#9A9892` | secondary text |
| `--blood` | `#E6393B` | primary action, health, accent |
| `--blood-deep` | `#7A1012` | shadows, heavy attacks |
| `--devil-violet` | `#7A3BFF` | devil faction, esper |
| `--cyber-amber` | `#FFB020` | meter, highlights |
| `--steel-blue` | `#4A7CFF` | cyborg, frost |
| `--frost` | `#7AD8FF` | monster faction accents |

**Typography**
- **Display:** `Barlow Condensed` (700/800/900) — condensed, industrial, aggressive. Used for titles, fighter names, round banners. Chosen because its tight letterforms read instantly at large scale and evoke distressed comic headlines.
- **Body:** `Space Grotesk` (400–700) — geometric sans with subtle quirks, clean at small sizes for descriptions and HUD.
- **Mono:** `JetBrains Mono` (600/700) — numbers, timers, labels. Monospace ensures timer and damage readouts don't jitter.

**Iconography** — No emoji, no icon fonts. Every icon is a hand-built inline SVG path in `src/ui/components/icons.ts` (play, swords, gear, trophy, sound, back, close, pause, check, skull, zap). Stroke width 1.6–1.8, rounded joins, consistent 16×16 viewbox.

**Primitives** — `btn-primary` is a skewed clip-path (`polygon(6px 0, 100% 0, calc(100% - 6px) 100%, 0 100%)`) in blood red with glow, not a rounded purple gradient. `btn-ghost` is a muted panel with 1px line border and blur. Spacing scale `4/8/12/16/20/24/32/40/48` used everywhere. Shadows: `0 8px 32px rgba(0,0,0,0.6)` + inner highlight. Transitions use `cubic-bezier(0.16,1,0.3,1)` (ease-out) and `0.34,1.56,0.64,1` (spring).

## Core Systems

### Input & Timing (`src/core/*`)
- **InputManager** — WASD/Arrows + J/K/Q/E/R/Shift + gamepad axes/buttons. 8-frame input buffer + queue so combos (light > light > heavy > special) feel responsive despite 3–7f startup.
- **Timing** — hitstop (freeze-frame 6–22f), timescale slow (0.35–0.45× for heavies/ultimates), screen shake (3–14px) with exponential decay. Both are tunable per move.
- **Camera** — tracks midpoint of fighters, lerps (`0.12`) to keep both visible within 1400px stage. Shake offsets applied in world-to-screen.

### Combat (`src/combat/*` + `src/entities/*`)
- **Fighter** (`src/entities/fighter.ts` ~400 LOC) — base class: physics (gravity `0.85`, jump `-14.5`, friction `0.82`, dash `9` speed / `14f` duration / `8f` back-dash i-frames), state machine (`idle, walk, run, crouch, jump, fall, dash, attack, hitstun, blockstun, down, parry`), hitbox/hurtbox AABBs, throw boxes, meter, combo, heat, lifesteal, blood fuel.
- **Hitbox/Hurtbox** — AABBs per frame; active-phase only. `intersect()` O(1) checks for melee and projectiles.
- **Projectile** — 22×14 sprite, velocity, 90f life, 6-point trail. Gun Burst spawns 3 staggered; esper meteors fall with gravity.
- **MeterSystem** — 0–100, gain on hit/block, spend for ultimate (one true super per character with distinct visual swell). Ghost chip trail on health bar.
- **ComboSystem** — light > heavy > special chaining within 42f window; damage decay `0.85^(n-1)` prevents infinites.
- **Parry/Clash** — 6f parry window; success gives 22f punish (+ meter) and attacker hitstun.
- **Block** — hold back relative to facing; chip `18–35%` on specials, blockstun `0.6×` hitstun.

### CPU AI (`src/ai/*`)
A **behavior-weighted FSM** that considers:
- spacing (distance bucket), opponent's move phase (`startup/active/recovery`), own meter/health, whiff-punish opportunity.
- **3 difficulties** (`src/ai/difficulty-profiles.ts`):
  - *Novice* — 14f reaction delay, 55% accuracy, 40% aggression, 35% punish, 45% block.
  - *Veteran* — 7f delay, 78% accuracy, 62% aggression, 68% punish, 72% block.
  - *Nightmare* — 3f delay, 92% accuracy, 82% aggression, 88% punish, 84% block.
- Not just damage scaling — reaction time, decision accuracy, aggression weighting, meter threshold (40% vs 70% health) and whiff-punish distance all change.
- **Per-character personality** (`src/ai/behavior-weights.ts`): e.g. KAZU favours counter-baiting and `special2` parry, MIRA favours retreat+zoning, REX favours approach+heavy. Weighted random pick with occasional deliberate “mistake” when `Math.random() > accuracy`.

### Rendering (`src/render/*`)
- **StageRenderer** — 3 code-drawn arenas with parallax (0.15–0.4), each with ambient animation that never distracts: Rooftop (70 stars + 110 rain streaks + flickering neon), Warehouse (hazy light + crane + 24 dust motes), Desert (sun glow + dunes + 18 drifting dust). Ground is a textured strip with accent edge gradient and vignette.
- **ParticleSystem** — circles/rects/sparks with gravity, rotation, alpha decay. Hit sparks per attack type, block sparks (`#7AD8FF`), dash trails, teleport bursts.
- **Hit-effects** — screen shake, hitstop, timescale, overlay flash on ultimate swell.

### Audio (`src/audio/*`)
Real **Web Audio synthesis** — no single beep placeholders. `AudioEngine` builds sounds from oscillators, noise buffers, BiquadFilters, ADSR envelopes and a programmatically-generated convolution reverb impulse (1.2s decaying noise). Three gain buses: Master / SFX / Music, persisted to `localStorage`.

| Event | Design |
|---|---|
| Light hit | 880 Hz square + 4200 Hz noise burst + 140→70 Hz sub thump |
| Heavy hit | 520 Hz square + 90→38 Hz sub + 1800 Hz noise + 48 Hz sine |
| Block | 1200 Hz high-pass noise + 320 Hz triangle |
| Dash | 2600 Hz high-pass noise + 600→220 Hz sawtooth swell |
| Special charge | 220→480 Hz sawtooth rise + 3000 Hz noise |
| Projectile | 740→380 Hz square + 5200 Hz burst |
| Ultimate | 3-layer 110→220 Hz sawtooth rise over 0.45s, then heavy hit + 62 Hz sub |
| KO | 110→28 Hz sine + 900 Hz noise + 180→90 Hz square |
| Round sting | 520→660→880 Hz squares + 0.55 music bed |
| Win / Lose | 440 Hz triangle arpeggio (0/4/7/12 semitones) vs 330 Hz descending |
| Menu | 820 Hz sine move, 660+880 Hz confirm |
| Ambience | Rooftop: 1400 Hz bandpass noise + 55 Hz triangle pad; Warehouse: 42 Hz sawtooth + 800 Hz high-pass wind; Desert: 38 Hz sine + 110 Hz bandpass |

Volume sliders in Settings actually route to the three buses and persist.

## Build Order & Iteration

1. **Foundation** — scaffold Vite + TS, game loop accumulator, input manager with buffer, canvas pipeline, rectangle fighters with gravity/dash/double-jump.
2. **Combat core** — AABB hitbox/hurtbox, light/heavy, hitstun/blockstun, health bars with ghost trail, one fighter vs dummy.
3. **Full roster** — 8 `FighterDef`s, per-move frame data, idiosyncratic passives (Blood Fuel, Overheat, Fear, Pull).
4. **AI** — FSM + personality weights, 3 difficulty profiles, spacing/punish/block/projectile zoning, meter-aware ultimate logic.
5. **Visual polish** — vector fighter renderer (limb animation per state, attack extension, archetype helmets/masks), particle sparks (geometric per attack type), stage parallax + ambient particles, shake/hitstop.
6. **Audio** — `AudioEngine` with oscillators/noise/filters/envelopes/reverb, 13 designed SFX + 3 ambience beds + round/win fanfares.
7. **UI shell** — menu with parallax grid, character select with portrait canvases, stage select, HUD with custom bars/pips/timer, pause/settings with real sliders, round banners, results with session stats.
8. **Meta** — `localStorage` for volumes, difficulty, `duels_stats` (W/L) and `duels_history` (last 20 matches).
9. **Final pass** — balance tuning (startup/active/recovery per move), visual consistency (radius, shadows, skew), audio level pass, README.

## Balance Notes

All numbers live in `src/data/balance-constants.ts` and per-move `FighterDef`. Global gravity `0.85`, jump `-14.5`, run `5.6`, back-walk `2.6`, dash `9` for `14f` with `8f` back-dash i-frames + `18f` cooldown. Chip `18%` (light) to `35–50%` (ultimates). Combo decay `0.85`, window `42f`. Parry `6f`, punish `22f`. Stage `1400px` wide, camera lerp `0.12`. Round `99s`, best-of-3.

Ultimates cost `100` meter, gain `6–14` per hit; chip on block for ultimates forces respect. SENSEI's 55-damage ultimate requires counter-punish window (otherwise 0.45×) to keep the “one punch” fantasy fair.

## What's Not Included (by Design)

- No network multiplayer — local vs CPU only (adding netcode would double scope and require rollback).
- No sprite sheets — all art is procedural to avoid stock assets and keep the repo self-contained.
- No external audio files — synthesis keeps the build < 120 KB gzipped and avoids licensing.
